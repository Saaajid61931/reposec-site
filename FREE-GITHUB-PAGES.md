# Free GitHub Pages Fallback

Use this if you do not buy `reposec.site` yet.

## Public URL

After publishing a repo named `reposec-site`, the free GitHub Pages URL usually looks like:

```text
https://<your-github-username>.github.io/reposec-site/
```

Use the exact URL shown in GitHub repo Settings -> Pages.

## Important

Do not upload `CNAME` for the free version. `CNAME` is only for the custom domain flow.

Use `reposec-site-deploy-free-github-pages.zip` when you want the free GitHub Pages launch.

Use `reposec-site-deploy-domain.zip` only after buying the domain.

## Outreach Link Swap

In `OUTREACH.md`, replace:

```text
https://reposec.site
```

with your GitHub Pages URL before sending messages.

## Fastest Path

1. Publish the free GitHub Pages page first.
2. Open `LIVE-SEND-BOARD.html`, paste the free GitHub Pages URL, and send it to 15 warm or permission-safe leads.
3. Buy the domain only after the offer gets interest or the first payment is close.
