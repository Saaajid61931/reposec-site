How to Play RepoGotchi

Your pet hatches as an egg or baby. The more you commit, the more XP your pet gains to level up. If you code in JavaScript/CSS, it becomes a Web Sprite. If you code in Rust/Go, it becomes a System Golem. If you don't commit for a day, it falls asleep (enters Repose). Inactivity for days makes it sick, and eventually, it turns into a ghost.

100% Free & Privacy-Protected

The game runs client-side. We do not store your repository logs or passwords on any server. Private commits are counted locally using your Personal Access Token, which is kept entirely inside your browser's private vault.
